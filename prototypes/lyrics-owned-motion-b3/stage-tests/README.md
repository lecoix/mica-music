## 三层测试契约

**Behavior Contract**：无旧行反向下落；间奏“上方平滑移动、下方仅不受插入造成的额外位移”；所有可见歌词在用户手动滚动时响应相同 scroll；Seek/切歌/回收后新状态是唯一 authority；用户媒体数据不会因测试被覆写。

**Architecture Contract**：真实 `LazyColumn` 是 scroll/layout authority，B3 的自有动画只拥有残余 placement；旧 receipt/pin 在生命周期变更时失效；事件有唯一消费点，动画/几何/监听缓存有界。不能让“间奏持续时间”变成“持续覆盖用户触摸”的条件。

**Implementation Verification**：纯数学/状态逻辑 + 真实 `ExpandedLyricsPanel` Compose/Robolectric + 真机实际触控/录屏 + 真正音乐播放链四类证据独立计数。未测不能算通过，旧版本通过不能自动代表新提交通过。
