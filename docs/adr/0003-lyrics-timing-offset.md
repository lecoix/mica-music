# ADR 0003：歌词时间偏移

状态：已接受（2026-08-13）

## 决策

- 歌词时间不再包含隐藏的 `150 ms` 提前量；零偏移严格使用播放器位置。
- 用户偏移语义与 PixelPlayer 一致：正数让歌词提前，负数让歌词延后。
- 有效偏移为 `全局偏移 + 单曲偏移`；两层分别限制在 `-5000..5000 ms`。
- 仅在解释歌词时间时计算 `歌词位置 = 播放位置 + 有效偏移`，不修改音频位置、播放进度条或歌词文件。
- 点击歌词行 seek 时使用逆变换 `播放位置 = 歌词时间 - 有效偏移`。
- 全局偏移保存在歌词偏好中。曲库歌曲的单曲偏移独立保存在 Room
  `song_lyrics_offsets`，同时校验 `songId` 与 `mediaUri`，且不随曲库清空或重扫删除；
  临时外部歌曲仅保存在当前进程会话。
- 播放页、迷你播放器、首页信息行、通知、车载及外部歌词输出共用相同的偏移语义。

## 容量与并发

单曲表只为实际调整过的歌曲保存一行。运行时只订阅或读取当前歌曲，不为 10,000 首曲库
建立常驻偏移映射；临时映射只包含当前进程中被调整过的外部歌曲。

持久化写入由 `SongLyricsOffsetStore` 单一 owner 经 mutex 串行化。每首歌曲的写请求先分配
request revision，并在进入副作用及不可取消的 DAO 写入返回后重新校验；旧请求不能发布为最新结果。

## 入口

- 设置 → 歌词 → 全局歌词偏移。
- 播放页封面长按菜单 → 歌词偏移。
- 歌词页右上角调节按钮 → 歌词偏移。
