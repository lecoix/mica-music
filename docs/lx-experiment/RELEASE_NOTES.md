Mica LX 0.4.4-lx.1 是基于正式版 0.4.4 的独立实验版。

- 独立应用 Mica LX（com.mica.music.lx），可与正式版同时安装；不会覆盖正式版数据，也不自动迁移旧 lxexperiment 数据。
- 支持导入 LX 音源、QQ/酷我/网易/酷狗在线搜索、选择品质播放、加入队列/歌单，以及按需歌词和封面。
- 保留 0.4.4 的本地/远端曲库与音频路径，不自动降低所选音质。
- 专属更新清单；此版本为 prerelease，不替代正式版 v0.4.4 的 Latest 发布。

这是实验版。本轮未连接 Android 设备，尚未完成迁移后真机播放、第三方源兼容性和 8 GB/一万首完整逐字歌词的内存峰值验证。第三方服务是否可用及实际音质取决于音源；解析成功不等于可播放。脚本运行时没有进程隔离或原生无限循环中断。

64 位手机通常选择 64bit APK；32 位设备选择 32bit；不确定时使用 universal。
